# ai-prd-writer 回放验收（v1.0.1）

## 这是什么

不是客户交付物，是**自测记录**：拿 3 个虚构场景走一遍 skill 的完整流程（P0→P1→P2→P3），看产出的 PRD 在结构、可信度、可评审性上过不过关。

**全部内容为演示虚构**：公司、人数、金额、指标、时间一律假造，不得引用为事实。真实数据一条没有。

## 为什么要做

v1.0.0–v1.0.1 只验证了「格式合规」（`lint.py` 全绿、20 条触发用例方向正确），没验证「产出的 PRD 能不能进评审会」。格式对但内容是空话的 PRD 一样是废纸，所以要跑内容层。

## 怎么测的

1. 先写 3 个场景的一句话需求（P0 INTAKE 输入）。
2. 按 skill 的六条铁律，一轮一问，每题 3–4 选项 + 末位「你帮我定」；每题只取一个答案，取完即锁进字段表，不回头重问。
3. **模拟答案由我（AI）代填**，写成"用户"口吻的短句。这是本次方法的最大局限：用户答案是假的，所以测不出"真实用户会不会答偏"，只能测流程自身的稳定性与出稿质量。答案原文抄在各 PRD 顶部「回放输入」小节，可逐条核对 PRD 里每句话的来源。
4. 按 `references/template.md` 出稿，按 `references/checklist.md` 14 项自检，最后按 PRD v0.2 §3 的指标打分（见 `验收报告_20261121.md`）。

## 三个场景怎么选

刻意挑了 skill 的三种薄弱情形，不是挑好写的：

| 场景 | 压测点 |
|---|---|
| S1 工单归类 + 建议回复（AI 功能） | 用户连续 3 题答"不知道" → 看会不会追问、会不会编指标 |
| S2 采购比价线上化（纯流程，无模型） | 3/3a/3b 的「不适用 + 替代物」写不写得实 |
| S3 智能药盒（硬件 + 依从性统计） | 无外部工具调用 → 4a 该写【不适用】还是硬凑；硬件排期全未知 |
