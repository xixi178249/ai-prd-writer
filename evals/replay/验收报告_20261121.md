# ai-prd-writer 回放验收报告（v1.0.1 → 针对 v1.0.2 的改进输入）

> **演示样例，全部内容为虚构**：场景、用户答案、指标均为回放测试假造。
> 被测版本：`ai-prd-writer` v1.0.1（commit `a981e18`）｜测试日期：2026-11-21
> 被测对象是 **skill 的流程与出稿规则**，不是三位"用户"的业务判断。

## 一句话结论

流程跑得住：三份 PRD 都 12 节齐全、零绝对日期、没有把"不知道"变成编造。但自检清单与事实账本之间**有一处真冲突**（清单不承认「AI 代定」这个合法来源），另有 2 处规则没写到的地方被我在成稿时自行补了——这三件事该进 v1.0.2。

## 测法与局限（先说清楚，否则分数没意义）

1. 3 个场景各走一遍 P0→P1→P2→P3，**严格一轮一问**，每题 3–4 选项 + 末位「你帮我定」。
2. **用户答案由 AI 代填**（模拟答案原样抄在各 PRD 顶部）。这是最大局限：测不出"真实用户会不会答偏、会不会一次答三件事"，只测了流程自身稳不稳、出稿质量如何。
3. 评分由**写稿的人自己打**，存在自评偏差；首稿可用率这项尤其不可信，真实数字要等真人评审才能拿到。

## 逐份点评

**S1 工单归类（AI 功能，3 题答"不知道"）**
- 好：用户答"不知道准确率"后没有追问，直接落【待确认】，并在 §3.1/§3.3 给"建议值 + 理由 + 假设编号"，评审可以只否掉两个数而不动全篇。
- 差：长期目标线 `0.85 / 60% / 40%` 三个数只写了"依据"、没挂【假设】编号 → 就是那 4 处裸数字的来源。

**S2 采购比价（非 AI，无模型）**
- 好：3 / 3a / 3b 全部按"【不适用】+ 替代物"写成校验规则表（10 条规则）+ 验收用例表（10 条）+ 通过门槛（10 条全过），评审能直接拿表对吵；4a 也写了【不适用】但补了接口约束，没有变成"无约束"。
- 差：§3.2 我自行补了"验收用例集见 §3b"——skill 只规定了 3.1/3a/3b 的替代写法，**没写 3.2 怎么替代**。

**S3 智能药盒（硬件 + 有模型、无 Agent）**
- 好：剂量错误定成 0 例一票否决（与其他百分比指标分开处理）；硬件成本、量产档期一律"待确认"，没有编 BOM 与售价。
- 差：§6 成本整章空、§8 量产段空，导致这份 PRD"能立项不能定稿"——这就是首稿可用率没到 3/3 的原因，且不是 skill 的错，是输入真的缺。

## 发现的问题（按严重度）

**P0 · 自检清单与事实账本冲突（真 bug）**
`references/checklist.md` A1 原文："正文每个数字都能回溯到用户原话或材料原文；回溯不到的一律是【待确认】"——只承认 U / M 两种来源，**漏掉「A AI 代定」**。而 SKILL.md 的事实账本明确规定 A 来源合法、句末加【假设】即可。
后果：严格按清单执行的话，所有【假设】数字都要被改写成【待确认】，PRD 会变成一堆"待确认"、无法评审；反之按账本执行就违反清单。**两者必须统一**。

**P1 · 非 AI 场景缺 §3.2 的替代写法**
SKILL.md §五 写了 3.1 / 3a / 3b 的替代物，§3.2（评测集）没写。非 AI 场景下它同样不适用，需要一句"换成验收用例集，见 §3b"，否则执行者要么留空、要么瞎编一个"数据集"。

**P2 · 4a 写【不适用】后没有约束要求**
S3 无 Agent 链路，4a 按规则写【不适用】。但产品仍会对外动作（推送、下发计划、回写 ERP）。建议规定：4a 写【不适用】后**必须补一句对外的动作约束**，否则"不适用"变成"没人管"。

**P3 · 数字贴身标记没有明文要求**
账本只说"A 来源句末加【假设】"，没规定"一个数字与它的标记之间不许隔太远"。S1 的三个长期目标数字就因此漏标。建议写进清单：扫全文数字，每个数字 20 字内必须有标记。

## 结论：要不要改 skill

该改，但只改规则文本，不动 12 节骨架。三条（都是小改，合计约 15 分钟含重跑 lint）：

| 改动 | 文件 | 内容 |
|---|---|---|
| C1 | `references/checklist.md` A1 | 改成"回溯到 U/M/A/P 之一；A 来源必须紧邻【假设 A?】编号"（一次解决 P0 + P3） |
| C2 | `SKILL.md` §五 | 非 AI 场景补 §3.2 替代写法（验收用例集，指向 §3b） |
| C3 | `SKILL.md` §五 | 4a 写【不适用】后必须补一句对外动作约束 |

改完重跑：`lint.py`、三份回放 PRD 按新清单重检一遍、20 条触发用例（description 不动，结论不变）。
